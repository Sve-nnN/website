|----------|--------------|
| Public visitor → Media/Posts read | Unauthenticated users read published content and media files |
| Admin session → Users/Posts write | Only authenticated Payload admin users can create/update/delete |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-01-03 | Elevation of Privilege | Users/Media/Categories/Posts `access` config | mitigate | `create`/`update`/`delete` gated by `authenticated` on all four; `read` on Posts/Categories uses `authenticatedOrPublished` (drafts hidden from public), Media `read` is intentionally public (images must render on the public site) |
| T-01-04 | Denial of Service | Media upload `mimeTypes` | mitigate | Restricted to `image/*` only (tighter than the aprendoclub `image/*,video/mp4` analog) — reduces local-disk attack surface in Phase 1 before Cloudinary offload lands in Phase 3 |
</threat_model>
