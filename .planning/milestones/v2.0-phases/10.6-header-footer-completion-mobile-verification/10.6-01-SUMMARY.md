## Decisions Made

- Wordmark fallback (`font-heading text-heading`, clamp 22px-28px Khand semibold) already carries sufficient visual weight next to the new `border-b` — no change needed

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] Added visually-hidden SheetTitle for Radix Dialog accessibility**
- **Found during:** Task 1 (audit)
- **Issue:** `SheetContent` (built on Radix Dialog) had no `SheetTitle`. Radix Dialog requires an accessible name for its content; without it, React emits a console a11y warning and screen readers announce the mobile nav dialog with no name.
- **Fix:** Imported `SheetTitle` from `@/components/ui/sheet` and added `<SheetTitle className="sr-only">Navigation menu</SheetTitle>` as the first child of `SheetContent`.
- **Files modified:** `src/components/SiteHeader.tsx`
- **Verification:** `npx tsc --noEmit` passes; rendered HTML confirmed to include the `sr-only` element via `curl` against the running dev server.
- **Committed in:** `5681087` (Task 1/2 commit)
