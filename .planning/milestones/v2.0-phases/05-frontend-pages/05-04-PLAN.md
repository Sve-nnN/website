<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------|
| Rendered richText (Lexical) → HTML | Content authored by authenticated editors only (no public write path into richText fields) |
| ArchiveBlock category filter → DB query | `?category=` URL param from an anonymous visitor flows into a `payload.find` where-clause |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-04-01 | Tampering | `ArchiveBlock` category filter `?category=` param | mitigate | Validate the param against the real fetched `categories` list (slug allowlist) before using it in the `where` clause — reject/ignore unknown values rather than passing raw user input into the query |
| T-05-04-02 | Information Disclosure | `RelatedPosts`/`ArchiveBlock` queries | accept | All queries scope to public collections already exposed via `read: () => true` / `authenticatedOrPublished` — no new data exposure beyond what's already public |
</threat_model>
