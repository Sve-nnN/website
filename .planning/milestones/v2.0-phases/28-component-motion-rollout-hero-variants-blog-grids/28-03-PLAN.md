`src/components/ScrollReveal.tsx` (Phase 27, verbatim except this plan's `data-testid` addition):
```tsx
export function ScrollReveal({ children }: { children: ReactNode }) {
  const reducedMotion = useReducedMotion()
  return (
    <m.div
      initial={{ opacity: 0, y: 16 }}
      whileInView={{ opacity: 1, y: 0 }}
      viewport={{ once: true, amount: 0.3 }}
      transition={reducedMotion ? { duration: 0 } : { duration: 0.5, ease: [0.22, 1, 0.36, 1] }}
    >
      {children}
    </m.div>
  )
}
```
Add `data-testid="scroll-reveal"` to the `<m.div>` — purely additive, does not change behavior, gives 28-04's headless Playwright pass a stable selector to assert visibility against under `prefers-reduced-motion: reduce` emulation.
