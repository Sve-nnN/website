<decisions>
## Implementation Decisions

### Motivo (palabras de Juan)
- "me gustaría cuando me muestres los mockups de las páginas ver tal cual los componentes. Entonces si necesitas hacer un servidor de react mientras tanto para probar, hagamos eso."
- La fase 51 construyó portes vanilla propios (aproximaciones). A partir de aquí los mockups de páginas usan los componentes originales. Los portes quedan como referencia de peso y como fallback estático.

### Stack y aislamiento
- Vite + React 19 + TypeScript en `designs/redesign-v3/app/`, con `package.json`, lockfile y `node_modules` propios. `node_modules` y `dist` quedan fuera de git (agregar `.gitignore` local en la app).
- Variante TS + Tailwind o TS + CSS del registro de React Bits; elegir la que menos dependencias arrastre. Instalación por el registro JSON (`https://reactbits.dev/r/<Nombre>-TS-CSS.json` o equivalente verificado) o `npx shadcn add` dentro de la app, nunca en la raíz.
- Dependencias previstas por componente: `ogl` (PatternWaves, MicroSlats, algunos más), `gsap` y `motion` solo si un componente elegido las exige. Sin `three` salvo que Juan lo pida.

### Componentes
- Los 8 base: Grainient, PatternWaves, CRTWarp, MicroSlats, PixelBlast, PixelCard, GradientASCII, ASCIIText.
- Top 8 del scout (`51-REACTBITS-SCOUT.md`): Noise, Dither, Halftone Reveal, Pixel Transition, Faulty Terminal, Spotlight Card, Gradient Blinds, Star Border. Entran todos a la galería; Juan elige cuáles pasan a las páginas.
- Mantener la paleta y los tokens de la fase 51 (`tokens.css`) como props o variables CSS de cada componente.

### Licencia
- React Bits es MIT + Commons Clause. Uso en el portfolio personal de Juan, sin vender el código. Conservar cabeceras de origen y documentar en `LICENSES.md`. No es asesoría legal.

### Rendimiento y accesibilidad (sin cambios)
- 1 efecto pesado activo a la vez y 2 por página, carga diferida después de LCP (`React.lazy` + `IntersectionObserver`), pausa fuera de viewport, fallback estático (el CSS de la fase 51), `prefers-reduced-motion`, botón "Pausar animaciones".
- Superficies de lectura (blog, FAQ, case studies) sin shaders.
- El build de producción se mide con Lighthouse y se compara con el porte vanilla.

### Claude's Discretion
- Router (React Router o rutas simples), estructura de carpetas, organización de la galería.
- Cómo reutilizar `tokens.css` y los fallbacks de la fase 51.
- Estrategia de code splitting.

</decisions>
