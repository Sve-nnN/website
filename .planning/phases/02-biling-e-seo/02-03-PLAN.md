<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser request -> `src/middleware.ts` | Untrusted request path/headers cross into server-side redirect + locale-routing logic |
| Payload `redirects` collection (admin-write-only) -> middleware redirect target | Admin-authored data trusted as a redirect destination — never mixed with request-controlled input |
| Payload content fields -> `<script type="application/ld+json">` | Editor-authored (eventually) content rendered into a script tag — must be serialized safely |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-------------------|
| T-02-01 | Tampering (open redirect) | `src/middleware.ts` redirect-target resolution | mitigate | Redirect target is read exclusively from the `redirects` collection (`doc.to.url` or a resolved `refDoc.slug`), never from `request.nextUrl.searchParams` or any other request-controlled value; the collection itself is write-restricted to authenticated admins by Payload's default access control (no `create`/`update` access override was added to the `redirectsPlugin` config in Phase 1) |
| T-02-02 | Tampering (script injection) | `src/components/JsonLd.tsx` | mitigate | `JSON.stringify(data)` is used for the script body — never raw string concatenation of field values, which would allow a crafted content field (e.g. a title containing `</script>`) to break out of the JSON-LD block |
| T-02-03 | Information Disclosure | `src/middleware.ts` `runtime = 'nodejs'` | accept | `nodejs` runtime middleware runs entirely server-side on the self-hosted Hostinger Node process (not a client-reachable Edge function or client bundle) — the Payload Local API call and `DATABASE_URI` credential never leave the server process; this matches the same trust boundary as any other server-side Payload Local API call in `app/` route handlers |
| T-02-04 | Elevation of Privilege | `/admin`, `/api` matcher exclusion | mitigate | `config.matcher` explicitly excludes `admin` and `api` prefixes — verified by manual request to `/admin` post-implementation to confirm no locale prefix/rewrite is applied (RESEARCH.md Security Domain) |

</threat_model>
