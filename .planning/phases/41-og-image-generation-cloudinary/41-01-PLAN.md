```typescript
export function getCloudinaryOgWithTitle(url: string, title: string): string {
  if (!url || !url.includes('cloudinary.com')) return url

  const uploadIndex = url.indexOf('/upload/')
  if (uploadIndex === -1) return url

  const baseUrl = url.substring(0, uploadIndex)
  const afterUpload = url.substring(uploadIndex + '/upload/'.length)

  // Strip existing transformation segments to isolate the raw public_id.
  const segments = afterUpload.split('/')
  let pidStart = 0
  for (let i = 0; i < segments.length; i++) {
    if (/^v\d+$/.test(segments[i])) {
      pidStart = i
      break
    }
    if (/^[a-z]{1,3}_/.test(segments[i])) {
      pidStart = i + 1
      continue
    }
    pidStart = i
    break
  }
  const publicId = segments.slice(pidStart).join('/')

  // Truncate long titles and URL-encode for the Cloudinary text parameter.
  // In an l_text layer, `,` and `/` are transformation-parameter separators.
  // Cloudinary decodes the URL once before parsing the transform, so a single
  // encode (`%2C`/`%2F`) decodes back to a raw separator and yields HTTP 400 —
  // they must be DOUBLE-encoded (`%252C`/`%252F`) to survive as literal text.
  const truncated = title.length > 65 ? `${title.slice(0, 62)}...` : title
  const encodedTitle = encodeURIComponent(truncated)
    .replace(/%2C/g, '%252C')
    .replace(/%2F/g, '%252F')

  const baseTransform = 'w_1200,h_630,c_fill,g_auto,f_jpg,q_auto'
  const scrimLayer = 'l_portfolio:og-scrim/w_1200,h_300,c_fill/fl_layer_apply,g_south'
  const textLayer = `l_text:Array-Bold.woff2_70_right:${encodedTitle},co_white,w_1100,c_fit/fl_layer_apply,g_south_east,x_50,y_50`

  return `${baseUrl}/upload/${baseTransform}/${scrimLayer}/${textLayer}/${publicId}`
}
```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Payload editor content (page/post/case-study titles) -> Cloudinary transform URL string | Titles are embedded as a literal segment (`l_text:Array-Bold.woff2_70_right:{title}`) inside a URL whose other segments are transformation directives separated by `,` and `/` — a title containing those characters could otherwise break out of its parameter and alter the transform chain |
| `[locale]/layout.tsx` metadataBase / twitter card | Static, non-user-controlled config value; no input surface |
| `resolveOgBackgroundUrl` -> Media.url exposure | Surfaces an already-public Cloudinary asset URL (same one `next/image` already renders elsewhere) via a meta tag |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-41-01 | Tampering | `og-image.ts::getCloudinaryOgWithTitle` (title text embedded in the `l_text` Cloudinary transform layer) | medium | mitigate | Ported JuanPortfolio's production-proven double-encoding fix verbatim: `encodeURIComponent(title)` then `%2C`->`%252C` and `%2F`->`%252F`, so a title containing a comma or slash (Cloudinary transform-string separators) cannot break out of the `l_text` layer or inject/shift subsequent transform segments; `%` itself is already escaped natively by `encodeURIComponent`. Trust boundary is internal (Payload editors, not anonymous public input), which is why severity is medium rather than high, but the mitigation is cheap and already production-proven so it ships regardless. |
| T-41-02 | Information Disclosure | `resolveOgBackgroundUrl` / `Media.url` exposure via `og:image` meta tag | low | accept | The exposed Cloudinary URL is already a public asset URL served sitewide via `next/image`; a meta tag adds no new disclosure surface. |
| T-41-03 | Tampering | `[locale]/layout.tsx` static `metadata` export (twitter card, metadataBase) | low | accept | Static object literal, zero request-derived or user-controlled input. |
| T-41-SC | Tampering | npm/CLI installs | n/a | accept | Zero new packages installed this plan — `og-scrim`/`Array-Bold.woff2` already exist live in the shared Cloudinary account per 41-CONTEXT.md; no Cloudinary SDK/client added, URLs are hand-built strings against the existing `res.cloudinary.com` host. |
</threat_model>
