From node_modules/@payloadcms/ui (client export surface, confirmed present):
- `useField<TValue>(options?: { path?: string }) => { value: TValue; setValue: (v: unknown) => void; path: string; disabled: boolean }` — from '@payloadcms/ui'
- `Modal, useModal` — from '@payloadcms/ui' (re-export of @faceless-ui/modal). `useModal()` returns `{ toggleModal, closeModal, isModalOpen }`. `<Modal slug="some-unique-slug">...</Modal>` renders its children only while that slug is open; toggle/close by the same slug string.
- `FieldLabel` — from '@payloadcms/ui', `React.FC<GenericLabelProps>` (props: `label`, `required`, `path` — mirrors how Payload's own Text/Select fields render their label).
