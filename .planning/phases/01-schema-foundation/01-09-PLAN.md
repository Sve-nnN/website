| Boundary | Description |
|----------|--------------|
| Unauthenticated visitor → /admin | Payload's built-in admin auth (Users collection, `auth: true`) gates every admin route and API mutation |
| /api/graphql-playground | GraphQL Playground UI is enabled by default — exposes the schema shape to anyone who can reach the route |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-01-13 | Spoofing | `/admin` route reachable by anyone (route itself has no additional gate) | accept | Payload's `RootPage`/`RootLayout` internally enforce session auth before rendering any admin view or accepting any mutation — this is Payload's standard, ASVS V2/V3-compliant built-in behavior, no custom auth needed in Phase 1 |
| T-01-14 | Information Disclosure | `/api/graphql-playground` exposes the full GraphQL schema (including all 9 collections' field shapes) to any visitor who finds the route | accept | Low risk for Phase 1 — no sensitive data exists yet (no migrated content), schema shape disclosure is a common/accepted tradeoff for a CMS in active development; revisit disabling the playground in production before Phase 6 deploy if desired |
</threat_model>
