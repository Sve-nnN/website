<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Visitante anónimo (browser) → Next.js RSC/Route Handlers | request no confiable cruza acá (locale, slug, path, `from` param) |
| Next.js Data Cache (`unstable_cache`) → TODOS los visitantes subsecuentes | superficie nueva de esta fase: un valor cacheado se sirve a CUALQUIER visitante durante hasta 60s (o hasta el próximo `revalidateTag`), amplificando cualquier gap de access-control en la query original |
| Editor admin (Payload) → hooks afterChange/afterDelete → revalidateTag | admin-authored, confiable, pero el hook debe usar el tag correcto o la invalidación no ocurre |
