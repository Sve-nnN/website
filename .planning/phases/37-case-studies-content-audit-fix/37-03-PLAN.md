Exact field shapes (from `src/collections/CaseStudies/index.ts`, already read in full during planning):

| Field | Path | Shape |
|---|---|---|
| Challenge | `challenge[]` | `{ text: string }[]` — `text` is `localized: true, required: true` |
| Solution | `solution[]` | `{ title: string, description: string }[]` — both `localized: true, required: true` |
| KPI | `kpis[]` | `{ label: string, value: string }[]` — `label` is `localized: true, required: true`; `value` is NOT localized (same across locales, e.g. "+83%") |
