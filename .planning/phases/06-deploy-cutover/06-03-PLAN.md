## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Panel DNS del proveedor → registros públicos | Cambio de alto impacto: afecta resolución global del dominio, tráfico real y ranking SEO |
| Registros de email (MX/TXT/SPF/DKIM) | Comparten el mismo dominio que el registro web que se está cambiando; tocarlos por error rompe el envío de Resend |
